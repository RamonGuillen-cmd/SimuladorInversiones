# Simulador de Inversiones

Actividad 1 correspondiente al desarrollo de un simulador de inversiones en Java.

## Descripción

El programa permite:

- Registrar clientes.
- Almacenar capital inicial.
- Registrar tasas de rendimiento mensual.
- Generar proyecciones financieras a 12 meses.
- Consultar información de clientes.
- Realizar búsquedas dentro de los arreglos y matrices.

## Tecnologías utilizadas

- Java Standard Edition
- Apache NetBeans
